# DnD-Hogwarts-Sorting-Game

## Overview

A gamified sorting experience where players choose a class from Dungeons and Dragons, answer scenario‑based questions, earn points for four Hogwarts houses, activate special abilities, and unlock badges based on their choices. At the end, the Sorting Hat reveals the player’s final house or, if multiple houses tie, invites the player to make a personal choice through a short tie‑breaker quiz.

The project is designed as a portfolio piece showcasing advanced Storyline techniques, including:

- Adaptive scoring and branching  
- GSAP‑powered animated progress bars  
- Character‑specific feedback  
- Badge unlock systems  
- A dynamic Final Reveal page  
- A custom Draw Sorting (tie‑breaker) mechanic

## Features

### Adaptive Scoring  
Each question awards different points to each house. Scores update visually using GSAP animations applied to Storyline shapes.

### Character Abilities  
Players choose a character class (Artificer, Druid, Paladin, Rogue). Each class has a one‑time ability that influences gameplay.

### Badge System  
Players can earn multiple badges based on their decisions, including:

- House Badge
- Determination Badge
- Destiny Breaker Badge
- Ability Master Badge

### Draw Sorting (Tie‑Breaker Quiz)  
If two or more houses tie for the highest score, the Sorting Hat presents a short personality question with only tie-breaking options available to choose. The player’s choice determines their final house.

### Final Reveal Page  
A fully animated reveal sequence including:

- Sorting Hat feedback  
- Personalized welcome message  
- Character artwork with adding a House-colored scarf after the final results
- Animated badges

## Technology

- Articulate Storyline 360  
- JavaScript for DOM manipulation  
- GSAP (GreenSock Animation Platform) for animated score bars  
- Storyline triggers for branching, scoring, and badge logic  
- GitHub Pages for hosting
- Canva for image design
- Suno AI for music creation
- Copilot AI to create project Documentation
- Chat GPT for test scenarios

## Usage

This project is published through GitHub Pages.  
To view or share the game:

1. Open the GitHub Pages link provided in the repository.  
2. Play the Sorting Challenge directly in the browser.  
3. No installation or Storyline software is required.
